01 / Por que criar um site para a academia?

O projeto surgiu como uma oportunidade de transformar meus estudos em algo ligado a uma necessidade real: apresentar uma academia fora das redes sociais e organizar informações em um endereço próprio na web.

Em vez de tratar o trabalho apenas como um exercício visual, procurei pensar na página como uma apresentação institucional: quem chega precisa entender rapidamente o contexto da academia e conseguir navegar pelas informações sem depender de conhecer o negócio antes.

02 / Como o projeto foi construído?

O repositório público usa uma estrutura web direta, com HTML, CSS e JavaScript. Também há arquivos de dados e uma área de tour, o que permitiu experimentar organização de conteúdo e interações sem depender de um framework para montar a página.

Essa escolha me ajudou a praticar fundamentos que continuam importantes em projetos maiores: estrutura semântica, estilos responsivos, comportamento em JavaScript e separação entre conteúdo e apresentação.

03 / O que este projeto representa no portfólio?

O MHouse Fit foi uma das experiências em que levei o desenvolvimento para além dos exercícios de curso. Ele representa uma tentativa de aplicar interface e código a um negócio local e de observar como decisões de apresentação mudam quando existe um contexto concreto.

A negociação comercial não seguiu como eu esperava. Por isso, o projeto é apresentado como parte da minha trajetória e prática, e não como um caso de sucesso comercial ou como resultado comprovado para a academia.

04 / O que eu continuaria melhorando?

Eu continuaria refinando conteúdo, acessibilidade, desempenho e a forma como a academia apresenta seus diferenciais. Também manteria a revisão de imagens e recursos mais pesados, porque o projeto possui arquivos visuais grandes e isso pode afetar a experiência em conexões mais lentas.

O projeto está publicado como estudo de portfólio. Esta página não atribui métricas, resultados comerciais ou depoimentos que não estejam documentados.
