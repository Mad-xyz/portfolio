01 / Objetivo do projeto

Desenvolvi o site da MHouse Fit para criar uma apresentação clara da academia na web. Meu foco foi garantir que qualquer pessoa encontre rapidamente as modalidades disponíveis, fotos do espaço, horários de funcionamento e canais de contato.

02 / Estrutura e layout

Organizei a página em blocos diretos: apresentação inicial, modalidades de treino, estrutura física e informações práticas. Cuidei da hierarquia visual e das cores para manter boa leitura tanto no computador quanto no celular.

03 / Tecnologias utilizadas

Construí o projeto com HTML5 semântico, CSS3 e JavaScript puro, sem bibliotecas ou frameworks externos. Essa escolha garantiu um carregamento rápido, código limpo e facilidade de ajuste.

04 / O que aprendi no desenvolvimento

Esse projeto me ajudou a consolidar conceitos fundamentais de responsividade com Flexbox e Grid, além de manipulação de layout para diferentes tamanhos de tela e organização de arquivos estáticos.

O site está publicado online para demonstração da interface e do código desenvolvido.
