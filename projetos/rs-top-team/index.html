01 / Qual problema o projeto resolve?

Criei o projeto para atender a uma necessidade prática: centralizar a rotina operacional de uma academia em um ambiente digital único. Em vez de espalhar cadastros, chamadas e dados financeiros em planilhas ou cadernos, estruturei módulos integrados para gerenciar essas informações.

Defini regras para que administradores, professores e alunos tenham acessos separados, mantendo a visualização organizada para o dia a dia.

02 / Funcionalidades que planejei e estruturei

Mapeei as necessidades da academia e estruturei os módulos do sistema: painel geral (dashboard), cadastro de alunos e professores, turmas e modalidades, chamada de presença com histórico, registro de graduações e controle financeiro de mensalidades e despesas.

Também defini o fluxo de autenticação por PIN e organizei o layout para funcionar bem no celular como aplicativo web (PWA).

03 / Tecnologias e uso de inteligência artificial

O sistema utiliza React no front-end e Firebase (Authentication e Firestore) no back-end. A maior parte do código foi gerada com o apoio de inteligência artificial: minha atuação foi direcionar os requisitos, desenhar as telas, orientar a lógica de cada componente, testar o comportamento e refinar o resultado.

Como ainda estou no processo de aprendizado de React e Firebase, essa abordagem me permitiu entender a estrutura de uma aplicação moderna na prática, mantendo o controle sobre o que o sistema entrega.

04 / O que aprendi com o projeto

Esse projeto me deu experiência prática em modelagem de dados, separação de perfis de usuário e refinamento de interface. Aprendi a identificar erros de integração, depurar regras de segurança no Firestore e ajustar a experiência para telas menores.

O código e a versão funcional estão disponíveis para demonstração das telas e fluxos implementados.
