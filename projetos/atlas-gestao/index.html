04 / Desenvolvimento Web · SaaS (Apoio de IA)

Atlas Gestão

Plataforma SaaS multi-tenant para academias que estruturei com foco em isolamento de dados e permissões, utilizando inteligência artificial como apoio no desenvolvimento com React e Firebase.

Estudo de Caso
SAAS / ACADEMIAS
ATLASGESTÃO
Plataforma SaaS multi-tenant.Projeto 04

01 / Qual problema o Atlas Gestão organiza?

Academias precisam gerenciar alunos, professores, turmas, chamadas e relatórios financeiros ao mesmo tempo. No Atlas, meu objetivo foi reunir esses fluxos em uma plataforma web integrada, desenhada desde o início para o modelo multi-tenant: diferentes academias usam a mesma aplicação com seus dados totalmente separados.

02 / Estrutura multi-tenant e organização dos dados

Planejei a estrutura no Firestore com isolamento por organização sob o padrão organizations/{orgId}. Cada cliente possui suas próprias coleções de usuários, modalidades, presenças e finanças, garantindo que uma empresa nunca visualize dados de outra.

03 / Tecnologias e uso de inteligência artificial

A aplicação utiliza React no front-end e Firebase Authentication com Firestore no back-end. A maior parte do código foi implementada com auxílio de inteligência artificial: minha responsabilidade foi definir os requisitos do sistema, desenhar as telas, orientar as regras de acesso e validar cada funcionalidade na prática.

Como ainda estou estudando React e Firebase, conduzir esse projeto me ajudou a entender na prática como estruturar o estado de uma aplicação e organizar regras de segurança no banco de dados.

04 / Evolução do projeto

O projeto segue como estudo contínuo. Minhas próximas metas são aprimorar os painéis administrativos e simplificar os relatórios para quem opera a plataforma.
