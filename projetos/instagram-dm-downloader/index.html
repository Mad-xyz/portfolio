Instagram DM Downloader

Ferramenta desenvolvida para facilitar o download de imagens e vídeos recebidos através das mensagens diretas do Instagram Web, otimizando tarefas repetitivas.

01 / Que necessidade a ferramenta atende?

O Instagram Web exibe mídias recebidas no Direct, mas não oferece um recurso nativo direto para salvar arquivos com um só clique. A extensão foi criada para eliminar essa fricção, inserindo botões de ação rápida e contextuais ao lado de cada elemento de mídia exibido nas conversas.

O foco é produtividade: abrir o chat, identificar o conteúdo e realizar o download instantâneo sem etapas manuais complexas.

02 / Mídias suportadas e funcionamento

A solução identifica e gerencia o download de fotos e vídeos preservando a qualidade original transmitida pela plataforma. O script monitora o fluxo de navegação para habilitar os botões conforme novas mensagens são carregadas na conversa ativa.

03 / Privacidade e execução local

A extensão opera com foco estrito em segurança e privacidade: nenhuma informação pessoal, mensagem ou mídia é armazenada ou enviada para servidores externos. Todo o processamento é executado localmente no próprio navegador do usuário.

04 / Desafios técnicos no contexto do DOM externo

Diferente de uma aplicação web isolada, criar uma extensão exige interagir com o DOM dinâmico de uma plataforma complexa de terceiros. Isso exigiu implementar MutationObservers eficientes para injetar botões sem causar travamentos, vazamentos de memória ou conflitos visuais com a interface original.

A extensão é um projeto independente de desenvolvimento de software em JavaScript e não possui afiliação com Instagram ou Meta.
