Instagram DM Downloader

Uma extensão criada para facilitar o download de imagens e vídeos recebidos em conversas do Instagram Direct pela versão web, mantendo a ação de download próxima da própria mídia.

01 / O que a extensão resolve?

O Instagram Web permite visualizar as mídias recebidas no Direct, mas o fluxo para salvar determinados conteúdos pode não ser direto. Este projeto nasceu como uma experiência prática para colocar uma ação de download junto das imagens e vídeos exibidos nas conversas.

O foco é reduzir passos: abrir a conversa, localizar a mídia e acionar o download pela própria interface adicionada pela extensão.

02 / Quais mídias o projeto suporta?

O repositório documenta suporte para download de fotos e vídeos recebidos nas mensagens diretas do Instagram. A extensão procura utilizar a mídia na qualidade original quando ela está disponível e foi pensada para funcionar na versão web do Instagram.

O suporte a grupos ou álbuns de fotos aparece no projeto como funcionalidade futura, por isso não é apresentado aqui como recurso concluído.

03 / Privacidade e instalação

De acordo com a documentação do próprio projeto, a extensão não coleta dados e não envia informações para terceiros. Ela é instalada localmente pelo modo de desenvolvedor do navegador, usando a opção de carregar uma extensão sem compactação.

Este projeto é independente e não possui afiliação com Instagram ou Meta. Essas limitações ficam explícitas para não transformar um experimento técnico em uma promessa maior do que ele realmente é.

04 / O que aprendi com o projeto?

A extensão me deu um contexto diferente de uma página comum: em vez de controlar todo o HTML, precisei pensar em como uma funcionalidade própria convive com a interface de outro site. Isso envolve observar elementos da página, criar ações de interface e manter o comportamento simples para quem usa.

O código está disponível publicamente no GitHub para que a implementação possa ser inspecionada junto deste estudo de caso.

A extensão é um projeto independente de portfólio e não é afiliada ao Instagram ou à Meta. Recursos descritos nesta página foram limitados ao que está documentado no repositório público.
