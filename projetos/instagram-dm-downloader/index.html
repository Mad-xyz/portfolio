03 / JavaScript · Extensão

Instagram DM Downloader

Ferramenta que desenvolvi em JavaScript para baixar imagens e vídeos direto das mensagens do Instagram Web, simplificando uma tarefa repetitiva.

01 / Por que criei a ferramenta

O Instagram Web não oferece uma opção direta de download para as mídias recebidas nas mensagens diretas. Criei esta extensão para resolver esse problema prático, adicionando botões contextuais ao lado das fotos e vídeos para salvar o arquivo com um clique.

02 / Como funciona

O script monitora as mensagens carregadas no chat e identifica os elementos de imagem e vídeo, criando um botão de download associado a cada um. As mídias são baixadas na qualidade original fornecida pela plataforma.

03 / Privacidade e execução local

Desenvolvi a extensão para rodar 100% no navegador do usuário. Nenhuma mensagem, imagem ou dado pessoal é coletado ou enviado para servidores externos.

04 / Desafios com a manipulação do DOM

O principal desafio foi lidar com a interface dinâmica do Instagram Web, que atualiza elementos continuamente. Usei MutationObserver para detectar quando novas mensagens entram na tela e inserir os botões de forma leve, sem quebrar o layout da página.

Esta extensão é um projeto pessoal de desenvolvimento em JavaScript para estudo e não possui afiliação com Instagram ou Meta.
